01 — שכבת הנתונים (Data Layer)
טוען תרשים...
📦 Word @Entity
מודל הנתונים הראשי של האפליקציה. מייצג מילה בשפה האנגלית עם תרגומה לעברית, נתוני למידה, וסטטיסטיקות תרגול. שמור ב-Room תחת טבלה words_table.
שדות (Fields)

Word()קונסטרוקטור ריק הנדרש ע"י Room
כל שאר המתודות הן getters/setters סטנדרטיים. Room דורש אותם כי השדות private.

07 — סנכרון Firestore (Throttle 24h + Diff)
טוען תרשים...
תרשים זה מתאר את תהליך הסנכרון בין Room DB המקומי לבין Firestore. הסנכרון מוגבל ל-פעם אחת ב-24 שעות למניעת עומס על Firebase.
שחקנים (Participants)
שחקןתפקיד
MyWordsViewModelמפעיל את הסנכרון בעת אתחול, בדיקת throttle
SharedPreferencesשומר את זמן הסנכרון האחרון (last_global_sync_ms)
WordRepositoryמבצע את הלוגיקה של הסנכרון
Firestoreמקור האמת לכלל המילים הגלובליות
ExecutorServicethread pool ל-4 threads — כל פעולות DB
Room DBבסיס הנתונים המקומי
שלבי הרצף
1
בדיקת Throttle: VM שואל SharedPrefs מתי היה הסנכרון האחרון. אם עברו <24 שעות → קפיצה לסוף (skip).
2
שמירת זמן: VM שומר את הזמן הנוכחי ב-SharedPrefs לפני הסנכרון.
3
שליפה מ-Firestore: Repository מביא את כל מסמכי collection "words" מ-Firestore.
4
שליפה מ-Room: ב-background thread, שולף רשימת englishWords של מילים גלובליות מ-Room.
5
חישוב Diff: firestoreSet = {englishWords...} ו-roomSet = {englishWords...}. מחשב הבדלים.
6
הוספת חדשות: מילים שב-Firestore אבל לא ב-Room → insert(word, isVerified=true)
7
מחיקת ישנות: מילים שב-Room אבל לא ב-Firestore → deleteVerifiedWordByEnglish(). כך Room מעודכן תמיד.
הסנכרון חד-כיווני: Firestore → Room. המשתמש לא כותב מילות admin בחזרה ל-Firestore. מילים אישיות (isVerified=0) לא מושפעות מהסנכרון.
08 — מחיקה בזמן אמת (Real-time Delete)
טוען תרשים...
כאשר מנהל מוחק מילה מ-Firestore, כל המכשירים המחוברים מקבלים עדכון בזמן אמת. הזרימה מתרחשת תוך פחות משניה.
שלבי הרצף
1
Listener פעיל: WordRepository מפעיל startGlobalDeleteListener() עם MetadataChanges.EXCLUDE — מאזין רק לשינויי שרת (לא local).
2
המנהל מחליק: AdminEditFragment מקבל swipe → removeItem(pos) מסיר מיד מה-UI (Optimistic Update).
3
מחיקה מ-Firestore: document(docId).delete() — בקשה אסינכרונית ל-Firestore.
4
Snackbar Undo: המנהל רואה מיד "נמחקה — בטל" עם אפשרות ביטול (insertItem בחזרה).
5
Event ל-Listener: Firestore שולח DocumentChange.REMOVED לכל המכשירים המאזינים.
6
מחיקה מ-Room: Repository קורא deleteVerifiedWordByEnglish() ב-background thread.
7
LiveData: Room triggers LiveData → Fragment מקבל רשימה מעודכנת → המילה נעלמת מכל מסכי המשתמש.
MetadataChanges.EXCLUDE: הListener מגיב רק לאישור השרת, לא ל-local cache. מונע "רטט" בממשק.
09 — זרימת חידון (Quiz + Gamification)
טוען תרשים...
זרימת סשן חידון שלם — מבנייה אדפטיבית של 20 שאלות, דרך תשובות ועדכוני XP, ועד dialog תוצאות.
שלבי הרצף
1
טעינת מילים: QuizFragment צופה ב-LiveData של ViewModel → מקבל את כל המילים מ-Room.
2
בניית סשן (buildSession): אלגוריתם אדפטיבי: 60% קשות (Mastery 0-2), 20% חדשות (0 ניסיונות), 20% מוצקות (Mastery 3-5). Daily: seed = currentTimeMillis/86400000.
3
לולאת שאלות (20 פעמים): הצגת שאלה, המתנה ללחיצת המשתמש.
4a
תשובה נכונה: correctAttempts++ → update DB → onCorrectAnswer(before, after) → +10 XP (ואם mastery 4→5: +100 XP) → update Firestore → אנימציה "+10 XP" → Handler.postDelayed(1000ms) → שאלה הבאה.
4b
תשובה שגויה: totalAttempts++ + errorInQuiz=true → update DB → ממשיך לשאלה הבאה.
5
סיום סשן: onModuleComplete() +50 XP → showResultDialog() עם OvershootInterpolator animation.
Handler.postDelayed(1000ms): נותן למשתמש שניה לראות הצבע ירוק/אדום לפני שעוברים לשאלה הבאה.
10 — זרימת סריקה (OCR + תרגום + שמירה)
טוען תרשים...
תהליך מלא מצילום תמונה ועד שמירת מילים. כולל תיקון סיבוב EXIF, OCR בשני מצבים, ותרגום offline.
שלבי הרצף
1
אתחול מצלמה: CameraX bindToLifecycle עם Preview (תצוגה חיה) + ImageCapture (צילום).
2
צילום: לחיצת "סרוק" → ImageCapture.takePicture() → savedUri של קובץ זמני.
3
תיקון EXIF: ExifInterface.readOrientation() → Matrix.postRotate() → Bitmap מסובב. בלי זה תמונות מצלמה אחורית הופכות.
4
OCR: ML Kit TextRecognizer.process(InputImage) → TextRecognitionResult.
5a
מצב ספר: extractWordBoxes() — Element level (מילה בודדת). מסנן Hebrew, punctuation, tokens קצרים.
5b
מצב טקסט חופשי: extractFreeTextBoxes() — Line level (שורה שלמה). לטקסטים שאינם ספרים.
6
מעבר ל-REVIEW: GraphicOverlay מציג מסגרות על המילות. ירוק = קיים בDB, כחול = חדש.
7
הורדת מודל תרגום: ML Kit Translate downloadModelIfNeeded() — פעם אחת ~30MB. לאחר מכן offline לחלוטין.
8
תרגום: לכל מילה → ML Kit translate(english) → hebrew. רץ offline.
9
שמירה: "שמור הכל" → לכל תוצאה: insert(Word, isVerified=false, isFavorite=true) → Room.
מילות OCR נשמרות עם isVerified=false (מילה אישית) ו-isFavorite=true (ב-MyWords). לא מסונכרנות ל-Firestore.
